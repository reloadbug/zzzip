# zzzip 项目设计说明书

> 版本 v1.0 ｜ 2026-10-14 ｜ 定位：Windows 平台极简绿色压缩工具（对标 360压缩 / 360zip）

---

## 1. 产品定位

| 维度 | 说明 |
|---|---|
| 名称 | zzzip |
| 目标用户 | Windows 7/10/11 家庭与办公用户，习惯用资源管理器右键操作 |
| 一句话价值 | 双击即用的绿色压缩箱：**右键就能压缩解压，不写系统目录、不弹广告、卸载只删文件夹** |
| 差异化 | ① 绿色便携（可放 U 盘）；② 默认零配置，高级项折叠；③ 右键菜单可一键开关并可层叠 |
| 明确不做 | 云同步、广告、捆绑、付费墙、浏览器接管、后台常驻进程 |

## 2. 对标分析（360zip 调研结论）

### 2.1 主界面信息架构

```
标题栏（图标 + 标题 + 最小化/关闭）
菜单栏：文件 编辑 查看 操作 工具 帮助
工具栏：添加 ｜ 解压到 ｜ 一键解压 ｜ 测试 ｜ 删除
列表区：名称 / 大小 / 压缩后 / 压缩率 / 修改时间
状态栏：项目数与大小统计 ｜ 双核引擎状态
```

特点：扁平化、无边框堆砌、浅色背景、绿色强调色、右上角工具区。

### 2.2 右键菜单逐条对齐

**普通文件 / 文件夹**

1. `添加到压缩文件…` → 【您将创建一个压缩文件】
2. `添加到"文件名.zip"` → 立即压缩到当前目录
3. `其他压缩命令 ▸`
   - `添加到高压缩比文件"文件名.7z"`（默认固实压缩）
   - `压缩每个文件到单独的压缩包中`
   - `添加到"文件名.zip"并邮件`

**压缩包**

1. `解压到"文件名\"`（360 的默认项）
2. `解压到当前文件夹`
3. `解压到指定文件夹…`

**开关项（工具 → 选项）**：层叠右键关联菜单（把每组折叠为 1 项）。

### 2.3 压缩 / 解压设置项

| 分组 | 项 |
|---|---|
| 目标 | 文件名、保存路径、添加到文件夹树 |
| 格式 | ZIP（默认）/ 7Z / TAR / GZIP |
| 等级 | 快速 / 标准 / 体积最小 |
| 固实 | 仅 7Z 可勾 |
| 分卷 | 1 MB ~ 9999 MB 自定义 |
| 加密 | 加密码，AES-256，输入两次校验 |
| 其他 | 添加注释、创建自解压 exe、解压后保留压缩包、覆盖策略 |

### 2.4 其他能力

45 种扩展名解压、压缩包内浏览、双击打开、文件关联管理。
云查杀（360 的卖点）本期不做，但保留 `SafetyRating` 评级位以便后续接入。

## 3. 总体架构

```
┌──────────────────────────────────────────────┐
│  Shell 层                                     │
│  资源管理器右键菜单 / 文件关联 / 拖放 / 命令行 │
└───────────────┬──────────────────────────────┘
                │ 进程启动 + 命令行 verb
┌───────────────▼──────────────────────────────┐
│  应用层 zzzip.exe（WPF）                      │
│  主窗口 / 压缩对话框 / 解压对话框 / 选项对话框 │
│  ShellVerbRunner：verb → 核心层动作           │
└───────────────┬──────────────────────────────┘
                │
┌───────────────▼──────────────────────────────┐
│  核心层 zzzip.Core                            │
│  ArchiveEngineRouter（内核路由 / 降级）        │
│   ├─ ZipEngine        → System.IO.Compression │
│   └─ SevenZipCliEngine→ 7z.exe 子进程          │
│  PathSafety（Zip Slip 防护 / 空间校验）        │
│  FormatRegistry（45 种扩展名）                 │
└──────────────────────────────────────────────┘
```

### 关键决策

| 决策 | 理由 |
|---|---|
| **不自研压缩算法** | ZIP 用 .NET 内置；其余全部驱动官方 7-Zip。360 自身也使用 7z 内核（LGPL），40+ 格式零维护成本 |
| **7-Zip 走 CLI 子进程，而非手写 7z.dll interop** | 7z.dll 的 COM vtable 槽位序号随版本漂移，PROPVARIANT 的 BSTR 跨边界释放极易崩溃；CLI 方式行为与官方完全一致、崩溃被隔离在子进程、`ArgumentList` 传参天然免疫中文/空格路径转义 |
| **右键菜单用注册表 verb，不做 COM DLL** | 见 README 专节。绿色、可靠、可自动化测试验证零残留 |
| **错误不阻塞** | 提供 `--silent`，自动化场景错误写 stderr 而非弹窗挂死 |

## 4. 技术选型

| 层 | 选型 |
|---|---|
| 语言 / 框架 | C# / .NET 10 |
| UI | WPF（自绘无边框窗口 + 自定义控件模板），矢量渲染最贴合 360 的扁平风格 |
| 压缩内核 | ZIP：`System.IO.Compression`；其余：官方 `7z.exe` |
| Shell 集成 | 注册表 verb（`HKCU\Software\Classes\...\shell`）+ 上下文菜单处理器键 |
| 配置 | 注册表（HKCU\Software\zzzip），便携模式可选 INI |
| 测试 | 自研零依赖测试运行器，退出码 = 失败数 |
| 打包 | 自包含发布（`--self-contained`） |

## 5. 数据模型

```
ArchiveFormat   Id / Extension / DisplayName / CanCreate / SupportsMultiVolume / Extensions[]
ArchiveEntry    Path / RawName / IsDirectory / Size / PackedSize / ModifiedUtc / IsEncrypted / Safety
ArchiveOptions  Format / Level / Solid / VolumeSizeMb / Password / EncryptFileNames
                / EntryRootPrefix / Comment / CreateSfx / KeepArchiveAfterExtract
                / OverwriteExisting / ExtractToSubFolderPerArchive
ArchiveProgress CurrentFile / TotalBytes / ProcessedBytes / FilesTotal / FilesDone
```

`IArchiveEngine` 抽象：`List / Extract / Create / Test` 四方法，
由 `SupportsEncryption / Solid / MultiVolume / Sfx` 四个能力位驱动 UI 的选项可用性。

## 7. 验收标准

| 项 | 标准 | 验证方式 |
|---|---|---|
| 菜单一致性 | 菜单文案与顺序与 360zip 一致；压缩包默认项为「解压到"文件名\"」 | 自动化断言菜单文案表 |
| 零残留 | 卸载后注册表无任何 zzzip 相关键 | 自动化遍历 45 个扩展名键 |
| 往返一致 | 压缩→解压后字节完全一致（含 10 MB 随机数据） | 自动化字节比对 |
| 加密有效 | 无密码/错密码解压必须失败，正确密码成功 | 自动化三段断言 |
| 越界防护 | 含 `../` 的恶意包被阻断且不落盘 | 自动化安全用例 |
| 不崩溃 | 7z.exe 缺失时降级为仅 ZIP 并给出中文提示 | 引擎路由单测 |

## 8. 风险与对策

| 风险 | 对策 |
|---|---|
| 用户机器无 7z.exe | 自动降级为仅 ZIP；UI 隐藏加密/固实/分卷/SFX 选项并提示获取方式 |
| 分卷包解压头卷识别 | 依赖 7-Zip 原生行为，卷名遵循 `.7z.001` 约定 |
| SFX 需要 `7z.sfx` 模块 | 缺失时测试跳过、功能项禁用，不视为失败 |
| 压缩包路径超长（>260） | 后续接入 `\\?\` 前缀 |
| 加密 ZIP 无法用内置内核 | 只要有 7-Zip 引擎即走 7z 写 AES-256 ZIP；否则明确报错 |
