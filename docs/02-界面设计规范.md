# zzzip 界面设计规范

> 风格目标：**清新、简单、扁平**。浅色底 + 绿色主色 + 极细描边，不使用渐变与阴影堆叠。
> 可交互原型：`prototype/ui-prototype.html`

---

## 1. 色板

| 用途 | 变量名 | 色值 | 说明 |
|---|---|---|---|
| 主色 | Accent | `#19A55A` | 图标、强调文字、进度条、选中态 |
| 主色（悬停） | AccentHover | `#138C48` | 按钮按下/悬停深色 |
| 主色（浅） | AccentSoft | `rgba(25,165,90,0.12)` | 工具栏悬停底、列表选中底 |
| 窗口背景 | WindowBg | `#F6F7F8` | 窗口最底层 |
| 面板背景 | PanelBg | `#FFFFFF` | 列表区、对话框正文 |
| 菜单栏背景 | MenuBarBg | `#FAFAFB` | 略低于纯白，拉开层次 |
| 描边 | BorderSoft | `#E3E6E9` | 1px 分隔线 |
| 主文字 | TextPrimary | `#23272B` | 正文与标题 |
| 次文字 | TextSecondary | `#8A9099` | 路径提示、状态栏 |
| 占位文字 | TextHint | `#B6BBC1` | 空列表提示 |
| 状态栏背景 | StatusBg | `#F1F3F4` | 底部信息条 |

**不使用**红色/橙色作为常规强调色，仅保留给错误提示与危险操作。

## 2. 字体与字号

| 用途 | 字号 | 字重 |
|---|---|---|
| 窗口标题 | 12 px | SemiBold |
| 菜单 / 工具栏 | 12 px | Regular |
| 列表正文 | 12 px | Regular |
| 列表表头 | 12 px | Regular（次文字色） |
| 状态栏 | 11–12 px | Regular（次文字色） |
| 空状态提示 | 13 px | Regular（占位色） |

字体族：`Microsoft YaHei UI` → `Segoe UI` → 无衬线兜底。
全局启用 `UseLayoutRounding` 与 `Display` 文本渲染模式，保证小字号清晰。

## 4. 主界面布局

```
┌──────────────────────────────────────────────────────────────┐
│ [z] zzzip                                        —    ✕      │ 40
├──────────────────────────────────────────────────────────────┤
│ 文件  编辑  查看  操作  工具  帮助                            │ 29
├──────────────────────────────────────────────────────────────┤
│ ＋添加  ⇩解压到  ⚡一键解压  ✔测试 │ 删除        未打开压缩包  │ 46
├──────────────────────────────────────────────────────────────┤
│ 名称            大小      压缩后     压缩率    修改时间        │
│ ──────────────────────────────────────────────────────────── │
│  （列表 / 空状态提示：拖拽文件到此处，或点击左上角「添加」）    │  *
│                                                              │
├──────────────────────────────────────────────────────────────┤
│ 12 个项目 | 原始大小 3.20 MB | 压缩后 1.05 MB   双核引擎状态  │ 26
└──────────────────────────────────────────────────────────────┘
```

要点：
- 工具栏按钮 = 图标（绿色）+ 文字，悬停出现 `AccentSoft` 圆角底。
- 工具栏右侧显示当前路径提示（次文字色）。
- 空列表时居中显示占位提示，不显示空表格。
- 状态栏左侧统计，右侧展示引擎状态（对应 360 的「双核引擎」提示位）。

## 5. 对话框规范

统一结构：**标题 → 表单行 → 说明文字 → 底部右对齐按钮**。

| 对话框 | 标题 | 字段 |
|---|---|---|
| 压缩设置 | 您将创建一个压缩文件 | 文件名、保存到（+浏览）、压缩格式、压缩等级、压缩分卷大小、固实压缩、创建自解压、加密码、确认密码、添加注释 |
| 解压设置 | 解压文件 | 解压到（+浏览）、密码、覆盖已存在文件、解压后保留压缩包 |
| 选项 | 选项 | 集成右键菜单、层叠模式、默认压缩格式、文件关联（全选/全不选） |
| 添加注释 | 添加注释 | 注释多行文本 |

规则：
- 标签列固定宽 72–84 px，左对齐；输入控件右对齐铺满。
- 主按钮在右，`立即压缩` / `确定`；次按钮 `取消` 使用 `IsCancel`。
- 密码输入使用 `PasswordBox`，不以明文回显。
- 底部一行灰色说明文字用于解释当前选项（例如选中 ZIP 时说明「ZIP 永远非固实」）。

## 6. 图标规范

| 图标 | 形式 | 颜色 |
|---|---|---|
| 应用图标 | 绿色渐变圆角方块 + 白色压缩包 + 拉链 + 字母 z | `#2BBF6E → #128C48` |
| 工具栏图标 | 线性符号（＋ ⇩ ⚡ ✔ 删除） | 主色 `#19A55A` |
| 窗口按钮 | 文本符号（— ✕） | `TextPrimary`，悬停 `#F0F1F2` 底 |

矢量源文件：`design/icons/zzzip.svg`。工具栏图标使用文本符号以保证任意缩放清晰，后续可替换为矢量路径。

---

## 7. 右键菜单视觉

沿用系统原生菜单外观（不改变用户既有习惯），仅定制菜单文案与分组：

- 普通文件/文件夹：3 项（含 1 个级联）
- 压缩包：3 项，第一项为默认动作
- 层叠模式：每组折叠为 1 项

菜单文案表见 `01-项目设计说明书.md` 第 2.2 节与自动化测试用例。

---

## 8. 可访问性与体验细节

| 项 | 做法 |
|---|---|
| 键盘 | 菜单栏全部带访问键（文件(_F) 等）；对话框主按钮 `IsDefault`，取消 `IsCancel` |
| 拖放 | 列表区接受文件拖入；压缩包直接打开，普通文件转入待压缩列表 |
| 长时间操作 | 状态栏右侧显示百分比与当前文件；列表禁用防止重入 |
| 错误提示 | 使用中文可读文案（如「压缩包条目越界，已阻止解压：xxx」），不暴露内部异常名 |
| 空状态 | 明确告知下一步该做什么 |

---

## 9. 与 360zip 的视觉差异说明

| 项 | 360zip | zzzip | 原因 |
|---|---|---|---|
| 主色 | 360 品牌绿 | 同色系绿 `#19A55A` | 保持「清新简单」的一致观感 |
| 皮肤 | 支持多彩皮肤 | 仅浅色一套 | 减少维护面，符合「极简」定位 |
| 云安全标识 | 有木马评级图标位 | 保留 `SafetyRating` 数据结构，UI 暂不展示 | 后续可接入本地扫描 |
