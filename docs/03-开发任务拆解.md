## 测试覆盖矩阵

| 需求 | 对应用例 |
|---|---|
| 45 种格式识别 | 格式注册表：扩展名解析与已知集合 |
| 恶意包防护 | 路径安全：Zip Slip 越界条目被拦截 |
| ZIP 往返正确 | ZIP 内核：多文件创建 → 列出 → 解压 → 内容一致 |
| 目录层级保留 | ZIP 内核：目录树层级被完整保留 |
| 部分解压 | ZIP 内核：仅解压选中条目 |
| 注释读写 | ZIP 注释：写入后可读回，覆盖写入正确 |
| 覆盖策略 | ZIP 内核：不覆盖模式下跳过已存在文件 |
| 损坏包处理 | ZIP 内核：遇到损坏数据抛出可读异常 |
| 7Z 往返 | 7-Zip 内核：7Z 格式创建 → 列出 → 解压往返 |
| AES-256 | 7-Zip 内核：AES-256 加密（三段断言） |
| 固实压缩 | 7-Zip 内核：固实压缩（体积对比 + 完整性） |
| 分卷 | 7-Zip 内核：分卷压缩（多卷 + 还原） |
| 自解压 | 7-Zip 内核：自解压 EXE（PE 头校验，缺 sfx 时跳过） |
| 大文件 | 大文件流式压缩：10 MB 随机数据往返无损坏 |
| **引擎降级** | 引擎路由：7z.exe 缺失时降级为仅 ZIP 并给出中文提示 |
| 菜单落位 | 右键菜单：verb 写在 `*\shell` / `Directory\shell` / `Drive\shell` |
| 命令契约（菜单） | 右键菜单：命令行为 `--verb=xxx "%1"`，且带图标 |
| 菜单文案 | 右键菜单：菜单文案与 360 对齐 |
| 级联菜单 | 右键菜单：「其他压缩命令」用 `SubCommands` + `ExtendedSubCommandsKey` 实现级联 |
| 层叠模式 | 右键菜单：层叠模式折叠为单项并撤下多余 verb |
| 零残留 | 右键菜单：卸载后无任何残留（含 1.0 版遗留的错误位置） |
| 选项持久化 | 右键菜单：选项可持久化并读回 |
| 文件关联 | 文件关联：写在 `Software\Classes\.ext` 下并指向自定义 ProgID |
| **关联可逆** | 文件关联：取消关联会还原用户原有的默认程序 |
| **关联幂等** | 文件关联：反复勾选再取消，仍还原成最初的原默认程序 |
| **默认动作** | 文件关联：默认动词是「打开」，不是就地解压 |
| **默认动词可逆** | 文件关联：取消关联会还原默认动词并收走「打开」 |
| **默认动词接管** | 文件关联：抢占别的程序已指定的默认动词，取消关联时还回去 |
| **图标落位** | 文件关联：图标写在扩展名键上，取消关联后还原 |
| **图标接管** | 文件关联：抢占别的程序已设置的图标，取消关联时还回去 |
| 命令行契约 | 端到端：6 个 verb + register/unregister/associate 往返 |
