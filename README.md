# zzzip

> 极简 · 绿色 · 无广告的 Windows 压缩工具（对标 360压缩 / 360zip）
> Windows 上双击即用的压缩箱：**右键就能压缩解压，不写系统目录、不弹广告、卸载只删文件夹。**

## 核心特性

- **右键即用**：菜单项与 360zip 逐条对齐，`解压到"xxx\"` 为默认动作。
- **绿色便携**：全部写入 HKCU，配置落在 exe 同级；卸载 = 删目录，注册表零残留（有自动化测试保证）。
- **双核引擎**：ZIP 走 .NET 内置实现（零依赖）；其余 40+ 格式驱动官方 7-Zip。7z.exe 缺失时自动降级为「仅 ZIP」并给出中文提示，**不崩溃**。
- **安全**：解压前做 Zip Slip 越界校验，恶意 `../` 条目被直接阻断；磁盘空间不足提前告警。
- **不阻塞**：`--silent` 模式下错误写 stderr，绝不弹窗挂死（供自动化/计划任务调用）。

## 快速开始

```bash
# 构建
dotnet build zzzip.slnx -c Release

# 运行自动测试（退出码 = 失败数，0 表示全部通过）
src/zzzip.SelfTest/bin/Release/net10.0-windows/zzzip.SelfTest.exe \
  --exe=src/zzzip.App/bin/Release/net10.0-windows/zzzip.exe

# 启动主界面
src/zzzip.App/bin/Release/net10.0-windows/zzzip.exe

# 集成 / 移除资源管理器右键菜单
zzzip.exe --register          # 完整菜单
zzzip.exe --register --cascade  # 层叠模式（只保留一个入口项）
zzzip.exe --unregister        # 完全移除
```

> 7-Zip 引擎需 `7z.exe`。查找顺序：环境变量 `ZZZIP_7Z` → exe 同级目录 → `PATH` → `Program Files\7-Zip`。

## 资源管理器右键菜单（与 360zip 一致）

**普通文件 / 文件夹**

| 菜单项 | 行为 |
|---|---|
| 添加到压缩文件… | 打开【您将创建一个压缩文件】设置对话框 |
| 添加到"文件名.zip" | 立即压缩到当前目录 |
| 其他压缩命令 ▸ 添加到高压缩比文件"文件名.7z" | 输出 7Z，默认固实压缩 |
| 其他压缩命令 ▸ 压缩每个文件到单独的压缩包中 | 每个文件各打一个包 |
| 其他压缩命令 ▸ 添加到"文件名.zip"并邮件 | 压缩后调起邮件客户端 |

**压缩包**

| 菜单项 | 行为 |
|---|---|
| 解压到"文件名\" | 默认项，自动新建同名文件夹 |
| 解压到当前文件夹 | 就地解压 |
| 解压到指定文件夹… | 打开【解压文件】对话框 |

开启「层叠右键关联菜单」后，上述两组各折叠为 1 项。

## 命令行参数

| 参数 | 说明 |
|---|---|
| `--verb=add\|quickzip\|7z\|each\|mail\|own\|here\|to` | 执行对应右键菜单动作（不弹主界面） |
| `--to=<目录>` | 配合 `--verb=to` 指定解压目标 |
| `--name=<名称>` | 指定输出压缩包名 |
| `--register` / `--unregister` | 注册 / 移除右键菜单 |
| `--cascade` | 注册时使用层叠模式 |
| `--silent` | 静默：不弹任何对话框，错误写 stderr |
| `--pick` | 启动时弹出「打开压缩文件」 |

## 设计说明：为什么用注册表 verb 而不是 COM Shell 扩展

常见做法是写 `IShellExtInit` COM DLL 并 `regsvr32` 注册。本项目刻意不采用：

1. **绿色性**：COM DLL 必须常驻加载进 explorer.exe，卸载容易残留，且加载失败会导致整个右键菜单异常；
2. **可靠性**：注册表 verb 方案永不出现「菜单丢失」，卸载就是删键；
3. **可测试**：注册/卸载可以用自动化测试完整验证「零残留」。

代价是无法做菜单项图标叠加与缩略图，这属于后续可选增强。
